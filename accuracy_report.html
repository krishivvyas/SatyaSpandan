Settings used

Thresholds: τ 55% · coherent windows ≥ 0.6 · signal quality ≥ 1 dB (≥ 2 dB to flag) · duration ≥ 6 s · background ratio ≤ 0.5, correlation ≤ 0.6 (only if background strength ≥ 0.5) · motion ≤ 0.05 · face found ≥ 0.8 · face ≥ 40 px.

Calibration file: none, built-in defaults.

Filter 0.7–3.0 Hz, 5th-order Butterworth; 10 s windows, 2 s step. Python 3.11.17, numpy 2.2.6.

SatyaSpandan results are probabilistic warning signs and can be wrong. They must never be used to definitively label a real person as a liar.
